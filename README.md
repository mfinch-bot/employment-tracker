# Employment Situation Summary

Dashboard do relatório de emprego dos EUA, com dados públicos do BLS.

- `scripts/update.py`: espera o dado novo, confere e publica
- `scripts/calc.py`: mesmas contas da aba Gráficos do Excel
- `scripts/charts.json`: definição dos gráficos
- `.github/workflows/release.yml`: agenda do robô
